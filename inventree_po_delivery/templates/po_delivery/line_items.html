{% comment %} Adds a "Delivered" / "Not Delivered" indicator to the rows of the Line Items table on the Purchase Order page (below the "Received" progress bar). InvenTree has no plugin hook for adding columns to its own tables, so this script (loaded on every page by the shared favicon.html override) watches the page for that table and adds the indicators to its rows: - The line item shown in each row is read from the props which the table (mantine-datatable) passes to each cell: "record" and "accessor". If this ever stops working (e.g. after an InvenTree upgrade), the indicators are simply not shown - nothing else in the table is changed. - The delivery state comes from the plugin API (/plugin/podelivery/lines/). It is re-fetched when switching tabs, when returning to the browser window, and after a change in the plugin's "Deliveries" panel. {% endcomment %}
